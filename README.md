# DCFer - AKA The Junk Drawer
Scripts for any occaision

## CDA_File_Research.py
Uses CDA and DCF report to try and get more detailed information about what in CRDC is being accessed.
## CDA_FileIDTest.py
Exploring how CDA does batch queries with File IDs
## CDABatchTimer.py
This script tries to get CDA Query performance times using a File IDs and different size batch queries.
## DCFer.py
Similar to FileAnalysis, uses a DCF report to generate basic usage.
## FileAnalysis.py
Parses a DCF report file and produces some basic usage stats.  Used mainly to understand what is being accessed.
## HTAN_File_Sheet.py
Generates a GC File load sheet for the 53 missing HTAN image files.
## KF_DCFSlicer.py
Reads a directory containing submission request Excel sheets and creates a summary report.  Used primarily to document all the program and study names/abbreviations use in the KF submissions
## SubDataType.py
This script generates a report of DH submissions that contains the type (Metadata only, Metadata and Files)
## DHReleasedCaseCounter.py
Generates a report of the number of cases in programs that have been released by DH.  Note that there are a variety of reasons why the case counts here do NOT match the case counts at the DCs.
## DHStudyEDPtimizer.py
Gets a list of the studies in DH for creating/maintaing the study EDP
